# Libron for CrossPoint

Libron by Nico Verbruggen (https://github.com/nicoverbruggen/libron),
converted to CrossPoint SD-card fonts at 10, 11, 12 and 13 pt.

## Install

Copy this `Libron` folder to `/fonts/` on the SD card, so the files sit in
`/fonts/Libron/`. Then pick Libron as the reader font in Text settings.
